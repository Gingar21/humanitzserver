RCON uses a similar implementation to vavle's rcon, you can use other tools to communicate or use the included app

info = Get current world info
save = Save game
QuickRestart = restart in 1 min also saves
Players = Fetch current connected players (name/SteamID)
fetchbanned = get list of banned player Steam IDs
RestartNow = Request server restart right away after saving
CancelRestart = Cancel restart request (useful with QuickRestart or Restart timeX)
admin message = replace message, will send a message to everyone in chat with admin tag. You can also just use the chat area.
kick NetID = where ID is the player steam ID (You can access it with Players command)
ban NetID = ban the player and kick em out of the game if currently connected
unban NetID = unban a certain player
teleport NetID = teleport the player to the nearest spawn location
unstuck NetID = unstuck player
restart X = replace X with minutes, this will request server restart.
shutdown = shut down server
season X = where X can be: spring, summer, autumn, winter
weather X = where X can be: clear, partly_cloudy, overcast, foggy, light_rain, rain, thunder, light_snow, snow, blizzard

//Below the commands you will find IDs for things like quests, items etc

spawnitem NetID ItemID Count                                       //Spawns the item in front of the player
spawnbackpack NetID BackpackID                                    //Same as abobe but a backpack
spawncar NetID CarID                                             //Spawn a car in front of the playe
spawnai NetID AIType Count Distance                             //Spawn AI near the player defined by distance
eventzombie NetID power                                       //Spawn zombie event that target all players. Power controls how many zombies and zombie types.
eventbandit NetID power                                      //Spawn but for bandits
addtoclan NetID ClanName                                    //Add player to a clan
kickfromclan NetID                                         //Kick a player from their current clan
settime time                                              //Set game time for example 2300 is 11pm
setdayspassed days                                       //Set game days passed, this controls zombie events 
resetspawners true                                        //This resets all spawners as if the game just started.
overridezeekmulti multiplier                             //Change zombie spawn multiplier
overrideanimalmulti multiplier                          //Same for animals
overridebanditmulti multiplier                           //Same for bandits
overridezeekrespawntime minutes                          //Change respawn time in minutes for zombies
overrideanimalrespawntime minutes                       //Same for animals
overridebanditrespawntime minutes                       //Same for bandits
suspendspawners true/false                              //When true it destroys all AI as if it despawned and pauses spawners. False resume back to normal.
clearinfection NetID                                   //Clear infection from a player
setinfectionamount NetID amount                       //Set infection amount 0 to 100. If 100 player will die to infection
fullhealth NetID                                     //Cleanse the player from all negative status and heal to full
setquestreadytocomplete player questID                  //Sets a quest to be ready to complete, gotta talk to the npc to complete and get rewards        
setquestcomplete NetID questID                         //Sets a quest to complete without having to speak to the npc but you get no rewards
forceresetquest NetID questID                         //Resets a quest as if you never accepted it. You can accept it again
incrementachievement NetID achievementID Amount      //Increment an achievement
overridexpmulti multiplier                          //Change XP multiplier
readallbooks NetID                                 //Unlocks crafting and building blueprints as if you read the book
forgetallbooks NetID                              //Forget all learned books, cancels above basically
unlocktrees NetID                                //Unlock all skill trees, you still need to spend points. You can follow up with /givexp if you need points
givexp NetID amount                             //Give XP to player, 500 for example can easily put you at level 12 from 1
tptoplayer Target Destination                  //Teleport one player to another where Target is the player being teleported
sendadminmsgto NetID message                  //Send a private message to a specific player only they can read it
fixcar NetID                                 //This will detect cars with bad location such as under the sea or in the sky and will teleport the car near the owner
fetchcardata NetID                          //This will fetch player owned cars with indexes, useful with modcarpos
modcarpos NetID INDEX X|Y|Z                //Use this to set a car position. The index you can get from fetchcardata. Careful with float values, you can just indicate integer positions.
modsave_pos NetID X|Y|Z                   //Mod the the player save to update player position, player has to be offline. Use it to fix saves. Full save modding will be added soon
fetchplayerdata NetID                     //This will fetch vitals, inventory and some stats. Info about symbols: Vitals: health|Hunger|Thirst|Infection
                                         //Stats: Ping|Level|DaysPassed|Clan|Profession|Gender
                                         //Inventory: ID@Count@Durability@Capacity and you will get Pos which is player position
                                         //For now player has to be online. I will provide full save stats once I add the save modding struct.
